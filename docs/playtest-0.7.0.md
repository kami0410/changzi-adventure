# 0.7.0 试玩说明 · 世界与同行者

日期：2026-11-01

## 这一版是什么

0.7.0 的目标不是再加一个系统，而是让世界“活起来”：敌人有更多种类和招式，角色有更完整的动作与特效，五个 Hub NPC 有自己的过去与职能，玩家的言灵能真正改变他们的服务；同时把默认帧率提高到 120。

## 新增内容

### 敌人

- 14 种敌人，新增：
  - **墨囊投手**：抛出会延迟爆炸的墨囊；双发夹击；大墨囊留下污染池。
  - **合唱召引者**：召唤残页小怪；召唤物会被房间正常追踪；第三段唱词治疗自己。
  - **镜面狙手**：先画预警线，再发射贯穿光束；单发/双线/三线扇射。
  - **残页群**：低血量高机动，绕圈后连续俯冲。
- 老敌人也增加了攻击变体：
  - 近战 3 段连击，第三段突进重击。
  - 远程单发/双发/蓄力三连。
  - 冲锋假动作、真冲锋、撞墙冲击波。
  - 飞行俯冲/羽弹/高速俯冲。
  - 精英近身重击、冲击波、落墨雨、跃击四段循环。

### 角色与动作

- 程序化骨骼动画：头、躯干、双腿分离；呼吸/跑步/跳跃/下落/落地/受击/施法/死亡。
- 玩家新增三段攻击、攻击突进、围巾飘带、奔跑扬尘、落地冲击环、受击击退。
- 敌人有攻击前摇环、受击回弹、死亡纸屑/墨爆；飞行敌人有翅膀拍动与尾迹。

### 特效

- 斩击/命中/死亡/施法/预警/冲击波/治疗/墨囊爆炸/光束命中全部重做。
- 技能形态共享墨晕、符文环、速度线和粒子。

### NPC 与言灵

- Hub 现在有五个 NPC：陆沉、阿砚、咕噜、闻烬、白榆。
- 每人有：
  - 3–4 段背景故事、性格、关键道具；
  - 两条职能；
  - 独立 AI 提示词；
  - 离线角色回复与关键词效果。
- 对 NPC 说言灵会改变：
  - 锻造折扣/免费锻造/锻造祝福；
  - 黑市折扣；
  - 起始残页；
  - 起始污染；
  - 情报与伤害祝福；
  - NPC 信任。
- 阿砚的身份从“守夜人”升格为“锻造之神 · 被遗忘的守夜人”。

### 剧情

- [剧情圣经](story-bible.md)：四章完整节拍、五个结局、五名 NPC 的弧光与关键道具。
- 四章开场/章末台词扩充，明确“名册—记忆—选择”的主线。

### 操作与帧率

- 默认 120 FPS，关闭垂直同步。
- H 打开操作说明；F10 → 键位设置可重绑所有动作。
- 每章两座宝箱，可开出武器/词/遗物/残页。

## 试玩路线

1. 从 Hub 和五个 NPC 分别对话，至少对阿砚说一句带“真名/锻造/神”的话，观察锻造折扣与神铸变化。
2. 进入第一章，走到第一座宝箱（约 x=3860）按 E，确认能开出武器/词/遗物。
3. 进入战斗房，观察敌人预警环与三段攻击；按 J 连打三段，感受第三段突进。
4. 按 H 查看操作说明；F10 → 键位设置，把攻击改成一个新键并试打。
5. 在设置里打开 AI 言灵，对 NPC 说一句自由的话，观察 AI 回复与职能变化。

## 已知限制

- AI 需要本机 Ollama 或兼容 API；没有配置时只有离线回应。
- 新敌人素材由 Magpie 生成后经 rembg 去背、缩放；部分边缘仍有轻微背景残留，正式发行前需要手工修边。
- 独立逐帧动画图集尚未制作，目前是单张纹理的程序化动画。
- Metroidvania Developer System 尚未安装；它是编辑器插件，需单独分支评估。
