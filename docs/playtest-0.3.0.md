# 昌子大冒险 0.3.0 三章冒险版

Windows：双击 `build/windows/changzi-adventure.exe`。Android：`build/android/changzi-adventure.apk`（debug 签名，尚未真机验证）。

## 这一版要解决的问题

上一版能打完，但只有四间固定战斗房，出发理由和章节目标都不够清楚。0.3.0 把单局扩成一条有开头、有推进、有选择、有收束的三章冒险，并补上标题与专属图标。

## 主线

陆沉在最后的档案馆告诉你：**名册被撕走了三页**。没有名册，死者会忘记自己的名字。

1. **第一章 · 墨雨档案馆**：穿过阅读厅与书库，击败墨骸史官，取回第一页。
2. **第二章 · 呼吸废墟**：在肺钟的雾气里找到第二页，击败肺钟守卫。
3. **第三章 · 无光海**：夜海、断钟与漂流档案之间，找到笑面史官，决定名册的下一页由谁书写。

每章有两场战斗遭遇、一间 Boss 房和一块可选残碑。章末会停下来播放回收剧情，并要求你做一个二选一决定。

## 词与法术

词库扩到 36 个，每个词在图鉴里会标出它改变的玩法维度（伤害、灼烧、护盾、移速、召唤、污染等）。组合出的短语会进入 8 种法术形态之一：

| 形态 | 词义线索 | 实际效果 |
|---|---|---|
| 焰 | 火 / 燃烧 / 闪火 | 前方扇焰，命中后持续灼烧 |
| 连锁雷 | 雷 / 风暴 / 轰鸣 | 在邻近敌人间跳跃，伤害递减 |
| 噬血束 | 血 / 悲鸣 / 吞噬 | 中距离墨束，命中回复生命 |
| 时渊 | 时间 / 静默 / 迟滞 | 留下持续减速与伤害的区域 |
| 护写 | 庇护 / 悬鱼 / 规则 | 获得护盾并推开近身敌人 |
| 回声 | 召唤 / 回声 | 召唤会自行追击的墨弹使魔 |
| 渊蚀 | 深渊 / 毒药 / 侵蚀 | 大范围高伤，额外污染 |
| 墨刃 | 记录 / 生命 / 权柄 | 三段近身连斩 |

图鉴的造句预览会显示“形态 + 词条”，HUD 的短语卡也会显示当前形态。不同组合不再只是换一个伤害数字。

## 结局

章末选择累积“仁慈”与污染，最终结算为：

- **复原**：保留记录、足够仁慈。
- **焚毁档案**：在最后一章选择焚毁。
- **深渊回响**：污染过高。
- **未完的注脚**：补全名册，但不够仁慈。
- **记录中断**：死亡。

结局、通关次数与残碑记录会写入 Profile。

## 操作

A/D 移动，空格跳跃（短按小跳、长按高跳），按住 J 连续攻击，L 翻滚（可穿敌），1/2 切换武器，Q/F 释放短语，E 读取残碑，Tab 背包，C 图鉴/造句，Esc 暂停，F10 设置。

## 试玩重点

1. 标题界面是否让你知道这是什么游戏、要做什么。
2. 三章的色调和背景是否区分得开；无光海是否有“最终区域”的感觉。
3. 换不同词组合后，技能是否真的换了一种打法，而不只是数字变化。
4. 章末选择是否让你犹豫；结局是否对得上你一路的选择。
5. 残碑是否值得绕路去拿。
6. 三个 Boss 的压迫感与可躲避性。

## 当前范围

这是 0.3.0，不是完整商业成品。独立手绘逐帧动画、更多生态区/支线、正式音频、Android 真机触控与性能仍未完成；第二章 Boss 目前复用精英敌人造型并做专属调色。遇到卡住、打不到、界面挡人或文字看不清，记录章节、房间和动作。
