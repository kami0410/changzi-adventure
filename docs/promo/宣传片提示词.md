# 《昌子大冒险》1.0 宣传片 · AI 制作提示词

> 用法：把「一、总提示词」整段交给负责做片的 AI，作为项目说明；「二」到「六」是它要遵守的分镜、旁白和逐镜生成提示词。
> 所有画面优先使用游戏里的真实素材（实机录屏、原画、立绘），AI 生成只用来补转场和氛围空镜，不能编造游戏里没有的玩法。

---

## 一、总提示词（直接粘贴）

```
你是一名游戏宣传片导演兼剪辑。请为独立游戏《昌子大冒险》1.0 正式版制作一支 75 秒的横屏宣传片（1920×1080，24/30 fps），另剪一支 30 秒竖屏版（1080×1920）。

【游戏事实，不得编造】
- 类型：2D 横版动作 Roguelite，像素美术，Godot 引擎，Windows 与 Android。
- 主角昌子：失忆的宇宙史官，黑短发、戴眼镜、黑色长风衣内衬暗血红、左臂夹一本青色魔法书。
- 世界：克苏鲁式污染侵蚀的末日废墟。名册被撕走三页，昌子要找回名字、权柄与记忆。
- 四章：第一章「墨雨档案馆」（蓝黑哥特档案馆、墨雨、飞舞书页）；第二章「呼吸废墟」（会呼吸的哥特废墟、巨大的肺钟）；第三章「无光海」（沉没的图书馆、黑太阳、巨型时钟残骸、水母）；第四章「笑面剧场」（猩红帷幕、金色包厢、提线木偶、笑面面具）。
- 核心玩法「言出法随」：玩家输入一句话，它就变成法术。例如「让时间停五秒」会让敌人定格，「一百颗追着敌人的火星」会放出追踪弹幕，「让三个敌人为我而战」会让敌人倒戈。可选接入 AI，AI 给出的数值不设上限，代价是墨量、冷却和污染。
- 战斗：翻滚加完美闪避、连段终结重击、武器掉落切换、敌人在地图各处游荡巡逻、精英与 Boss 锁门决战。
- Roguelite：每局每章随机一种「章节异象」（墨潮、血月、群鸦、静默、狂信、丰饶、雾锁、铁壁），另有每日挑战（当天全球同一种子）、五个结局。
- Boss：墨骸史官、肺钟守卫、最后的读者、笑面史官。
- Hub「最后的档案馆」：五位 NPC，陆沉、阿砚（前锻造之神）、咕噜、闻烬、白榆。
- 调色：午夜蓝 #141c2c / #23324a、墨黑描边 #0b0f14、骨白 #e8dcc4、干涸血红 #93222a、病态青 #8fe8dc（右上方轮廓光）。

【风格】
- 黑暗、压抑、诗意，带一点克苏鲁式的不安；不卖萌、不欢快。
- 节奏：前 20 秒慢（世界与谜题），中段 35 秒快剪（战斗、言灵、Boss），最后 20 秒收束（标题与发售信息）。
- 转场：墨水晕开、书页翻飞、纸张撕裂（与游戏内的墨晕转场一致）。
- 字幕与标题用像素风或宋体衬线字，骨白色，偶尔点缀血红。

【素材规则】
- 实机画面与原画优先；AI 生成镜头必须保持像素美术质感、同一调色和同一角色造型。
- 不出现游戏里没有的东西：不加多人模式、3D 画面、写实人物、现代城市、枪械大战。
- 不出现真人、不出现其他游戏的角色或标志、不伪造媒体评分或奖项。
- 画面里不要出现水印、乱码文字、多余的 UI。

【交付】
- 75 秒横屏成片 + 30 秒竖屏成片 + 封面图（16:9 与 9:16 各一张）。
- 附剪辑时间线（每镜起止时间、素材来源、是否为 AI 生成）。
```

## 五、配乐与音效

- 开头 0:00–0:22 用 `title.ogg`（名册动机的钟声），0:22 起叠 `chapter_archive.ogg`，0:36 切 `boss.ogg` 或叠 `chapter_archive_combat.ogg`，0:65 回到 `title.ogg` 的结尾或 `ending.ogg`。
- 关键卡点：言灵生效那一下（时停）全片静音 0.5 秒，再炸开；Boss 快切每镜对一记鼓。
- 音效可取游戏内 `assets/audio/*.wav`（翻滚、完美闪避、钟鸣、敌人死亡等）。
