# 昌子大冒险 0.4.0 言出法随 · 有声版

Windows：`build/windows/changzi-adventure.exe`；Android：`build/android/changzi-adventure.apk`（debug 签名，尚未真机验证）。

## 这一版最重要的变化

### 1. 没有语法了

以前必须凑“修饰词 + 动词 + 名词”，现在是 **1–4 个词任意组合**，顺序不限：

- 一个词也能成句（“生命”会变成护写，“雷”会变成连锁雷）。
- 重复词允许，但效果递减、污染增加。
- 词越多，墨耗/冷却越高、稳定度越低；不是越多越好。
- 词与词之间会出现共鸣（雷火、时焰、血护、渊召、生命·记录、时间·深渊等）。

### 2. 言出法随输入框

打开语言图鉴（C），在“言出法随”里直接输入一句话，点“推演”：

- “火焰”会匹配已拥有的“火”，推演出焰。
- “让雷落在火里”会匹配“雷”和“火”，出现雷火共鸣。
- “不可名状的低语”没有已知词，会生成一个确定性的“未名之词”——仍然可以装备、施放，只是更不稳定。

当前是**离线确定性推演**，不联网。未来接入 AI 时只让 AI 解析意图，数值仍由本地规则钳制；接口与安全约定见 [AI 技能钩子](ai-skill-hook.md)。

### 3. 八种法术形态

焰（扇焰+灼烧）、连锁雷（跳跃衰减）、噬血束（单体+吸血）、时渊（持续区域）、护写（护盾+推开）、回声（召唤使魔）、渊蚀（大范围+污染）、墨刃（三段连斩）。图鉴和 HUD 都会显示当前形态与稳定度。

### 4. 配乐与配音

- 五首原创循环配乐：标题、墨雨档案馆、呼吸废墟、无光海、Boss。
- 18 段中文旁白：陆沉任务、三章开场/章末、Boss 二/三阶段、五种结局。
- 剧情暂停时音乐与配音继续；语音期间音乐自动 duck。

> 配音是 Windows SAPI 的 Huihui 原型音色，**只用于试玩**。SAPI 的商用再分发授权不明确；正式发行前必须换真人或有商用授权的 TTS，并按规定披露 AI 语音。详见 [音频说明](audio/README.md)。

### 5. 动作继续加强

- 翻滚残影、施法残影、施法姿态。
- 相机前瞻（朝面向方向多看 32px）、受击/命中闪屏、Boss 阶段顿帧。
- Boss 登场 letterbox 与音乐切换；阶段转换有闪屏、震动与语音。
- 施法时在角色位置生成法术色环；火焰、连锁、时渊等有独立轨迹。

## 试玩重点

1. 在语言图鉴里只选 1 个词，看是否也能成句；再选 4 个，观察墨耗/稳定度变化。
2. 输入“让雷落在火里”，看雷火共鸣与形态；再输入一句没有已知词的话，确认仍然可施放。
3. 换不同组合打同一间房，比较“焰 / 连锁雷 / 时渊 / 护写”是否真的改变打法。
4. 听三章与 Boss 的音乐切换；听章节开场、Boss 阶段、结局旁白是否清楚。
5. 观察翻滚残影、施法姿态、Boss 登场和阶段转换是否足够有表现力，是否过闪/过慢。
6. 三章流程与章末选择是否仍然成立。

## 当前限制

- 配音为 SAPI 原型音色，机械感明显；正式版替换。
- 配乐为程序化合成，有 demo 感；可由正式作曲替换同名 OGG。
- 没有独立手绘逐帧图集；部分动作仍是程序分层动画。
- 第二章 Boss 仍复用精英造型并做专属调色。
- Android 未做真机触控/性能验证。
- 自由言灵的离线匹配以词义/ID/符文/读音为准；更自由的分词与 AI 解析是下一步。

遇到“这句话推演不出来”“技能没伤害”“音乐/配音不响”或“闪屏太强”，记录输入文本、章节和动作。
