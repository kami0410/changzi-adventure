# 《昌子大冒险》剧情圣经

> 版本：1.0 草案（2026-11-01）
> 用途：对话、章节、结局、NPC 台词与后续 DLC 的唯一剧情事实来源。
> 原则：先写人物，再写谜题；先写选择，再写解释。玩家不需要读懂全部设定，但要能感到每一页都有人在背后写过。

## 一句话

一个失忆的宇宙史官，在四个被记录吞掉的世界里，决定“谁来写最后一页”。

## 主题

- **记忆不是过去，是有人替你选择留下的版本。**
- **语言是权力。** 谁能命名，谁就能决定什么东西算存在。
- **爱不是保存，是允许对方改变。**
- **末日不是世界结束，是记录方式失效。**

## 世界规则

1. 世界由“原始语言”写成；宇宙史官是少数能直接改写它的人。
2. 名册记录所有存在者的真名。名字被涂掉的人不会死，只会被世界慢慢忘记。
3. 污染是“读到了超出人类容量的句子”。它给人力量，也让人成为句子的一部分。
4. 每一次改写都会留下“墨雨”：被删掉的记忆化成雨，落回世界边缘。
5. 笑面剧场是原始语言的装订厂。所有结局都在那里被装订成册。

## 主角：昌子

**身份**：宇宙档案馆最年轻的史官，也是唯一一个把自己的名字从名册上划掉后还活着的人。

**表象**：黑档案官外套、红内衬、破碎书卷、眼镜；说话短，习惯先观察再开口。

**内里**：昌子不是失忆，而是**主动选择忘记**。昌子知道上一任史官——也就是未来的自己——会把世界写成什么样子。昌子划掉名字，是为了让“笑面史官”无法找到自己。

**弧光**：
- 第一章：找回名字的碎片，但发现名字可能是假的。
- 第二章：看见别人如何被记住，开始怀疑“保存”是否等于“爱”。
- 第三章：知道所有结局，仍然选择继续走。
- 第四章：不再问“我是谁”，而是问“我要留下谁”。

**核心台词**：
> “我记得我选择记住谁。”

## 反派：笑面史官

**身份**：未来的昌子，或者说，是昌子所有可能版本中“最会写结局”的那一个。

**为什么笑**：他/她已经把每一种悲剧都写过一遍，笑是唯一不会在名册上留下修改痕迹的表情。

**目标**：让昌子回到舞台上，替自己完成最后一页——因为只有昌子能写出“连史官自己都愿意忘记”的句子。

**不是纯恶**：笑面史官相信，世界反复崩塌是因为总有人想保存一切。他/她选择把一切写成一个可以谢幕的故事。

**最终揭示**：他的脸后面不是脸，是一页写满“昌子”的名字的纸。每一个名字都是一次失败的重来。

## 四位同行者 / 五位 NPC

### 陆沉 · 档案长

- **职能**：解词、讲述档案、主线指引。
- **秘密**：他撕下三页名册，不是为了保护世界，而是为了保护自己不被写进“已死之人”那一栏。
- **弧光**：从“替昌子决定该读什么”到“承认自己也曾篡改”。
- **关键道具**：红色文件夹，里面是昌子最初的入职档案。
- **结局后**：如果仁慈足够，他会把红色文件夹交给昌子；否则它会出现在笑面剧场的观众席上。

### 阿砚 · 锻造之神 / 守夜人

- **职能**：武器基底升级、神铸、锻造祝福。
- **秘密**：他曾经是旧世界最后一座军械库的锻造之神。世界忘记他的神名后，他把自己降格成“守夜人”，因为守夜人不需要被记住。
- **弧光**：从“拒绝承认神格”到“愿意再为一个人烧一次炉”。
- **关键道具**：一把永远修不好的断页剑——其实是他给自己留的墓碑。
- **结局后**：如果昌子叫出他的真名，他会把锤子留在铁砧上，第一次走出铁匠铺。

### 咕噜 · 黑市商人

- **职能**：卖词、卖传闻、言灵折扣。
- **秘密**：它不是这个世界的生物，而是被烧掉的词堆里长出来的“记忆拾荒者”。它害怕的不是死，是没人再来买东西。
- **弧光**：从“什么都卖”到“有一件东西不卖”。
- **关键道具**：一只装着“永”字的玻璃瓶。
- **结局后**：如果信任足够，它会把瓶子送给昌子，说“这个不卖，借你”。

### 闻烬 · 篡改史官

- **职能**：情报、契约、Boss 弱点。
- **秘密**：她和昌子同门。她比昌子更早发现，改写记录比杀人更彻底。她曾把昌子的名字从一份死亡名单上改掉，因此被档案馆除名。
- **弧光**：从“用谎言活下来”到“承认自己也想被记住”。
- **关键道具**：昌子送她的断尖笔。
- **结局后**：如果信任足够，她会把笔尖磨好，重新写一次自己的名字。

### 白榆 · 引路人

- **职能**：地图、路线、起始残页。
- **秘密**：他不是活人，也不是地图。他是“所有没有走完的路”聚成的意识。他一直在等一个会回头的人。
- **弧光**：从“只带路”到“第一次和某个人一起走”。
- **关键道具**：一张没有终点的手绘地图。
- **结局后**：如果信任足够，地图上会出现一条从未有过的路，通向档案馆之外。

## 四章结构

### 第一章 · 墨雨档案馆

**目标**：找回名册第一页。

**节拍**：
1. 陆沉交代任务，昌子发现自己连名字都只剩一半。
2. 穿过阅读厅与书库，击败墨犬、空白人、抄写虫。
3. 墨骸史官登场：它是第一页的“守卫”，也是被涂掉名字的档案员。
4. 第一页背面出现一行与昌子笔迹相同的警告：不要相信替你保存记忆的人。
5. 章末抉择：带回档案馆（仁慈）或投入墨雨（污染 + 遗物）。

**Boss**：墨骸史官——一个把自己缝进书页的档案员，用墨雨和纸页攻击。

### 第二章 · 呼吸废墟

**目标**：让肺钟停下，取回第二页。

**节拍**：
1. 肺钟每响一次，就有一段记忆被呼出体外。
2. 阿砚带路，透露自己给肺钟打过一颗钉子。
3. 穿过塌陷街道，遇见肺蛾、喘息猎犬、合唱召引者。
4. 肺钟守卫是城市的“心跳”，也是把整座城锁在死亡瞬间的装置。
5. 第二页上全是死者的名字，阿砚看见了自己的名字。
6. 章末抉择：替肺钟续气（仁慈）或敲碎它（污染 + 武器强化）。

**Boss**：肺钟守卫——钟摆与肺叶组成的巨物，攻击有清晰前摇。

### 第三章 · 无光海

**目标**：穿过无光海，找到最后的读者。

**节拍**：
1. 无光海没有倒影；每一张脸都是别人丢失的。
2. 最后的读者是一个孩子，他读完了所有结局。
3. 镜面狙手、残页群、悬吊书吏在海上伏击。
4. 最后的读者告诉昌子：你会赢，也会输，还会在同一个地方反复醒过来。
5. 他交出空白的最后一页，并说“故事需要有人翻页”。
6. 章末抉择：带读者离开（仁慈）或留下最后一页（污染 + 遗物）。

**Boss**：最后的读者——用镜面弹幕和“读页”封印昌子的短语。

### 第四章 · 笑面剧场

**目标**：走上舞台，结束这场演出。

**节拍**：
1. 剧场坐满纸人，它们只为最后一页鼓掌。
2. 笑面史官逐一念出昌子同行者的名字，证明自己记得所有版本。
3. 舞台机关、纸人观众、镜面狙手与合唱召引者轮番登场。
4. 笑面史官揭示：他是未来的昌子，是所有失败版本的集合。
5. 最终战分成三个阶段：改写规则、删除词、复制昌子的武器。
6. 抉择：重写名册（以保存的记录决定结局）或焚毁名册（自由但失去历史）。

**Boss**：笑面史官——三阶段，每阶段改变战场规则。

## 结局

### 复原（Restored）
**触发**：胜利、仁慈 ≥ 2、污染 < 60、未焚毁。
**内容**：三页名册对齐，失踪者回到纸上。陆沉把红色文件夹交给昌子，阿砚走出铁匠铺，咕噜的瓶子空了，闻烬重新写下自己的名字，白榆的地图出现一条新路。
**余味**：昌子仍然不记得自己全部的名字，但记得自己选择记住谁。

### 焚毁档案（Burned）
**触发**：胜利、最终选择焚毁。
**内容**：名册烧了三天三夜。世界失去历史，也失去用过去命令任何人的权力。昌子第一次听见海的声音。
**余味**：没有档案的世界很轻，也很容易再次被写成同一个故事。

### 深渊回响（Abyss）
**触发**：胜利、污染 ≥ 60、未焚毁。
**内容**：昌子写下最后一页时，墨自己动了起来。昌子成为污染的一部分，也成为唯一还记得世界的人。档案继续生长。
**余味**：昌子终于读懂了所有句子，但已经没有“昌子”来读懂。

### 未完的注脚（Unfinished）
**触发**：胜利、仁慈 < 2、污染 < 60、未焚毁。
**内容**：名册补全了，却仍有一页空白。昌子合上档案，知道下一次潮水会带来新的名字。
**余味**：故事没有结束，只是暂时合上。

### 记录中断（Interrupted）
**触发**：死亡 / 放弃。
**内容**：污染吞没了这一页。昌子的名字从档案中淡去，但记忆碎片已经被写下。
**余味**：下一次，你会记得更多。

## 叙事投放

- **章节开场/章末**：`StoryOverlay`，每章 4–8 句，只讲人物关系，不讲设定百科。
- **NPC 对话**：每人 3 条常驻台词 + 言灵自由回复 + 职能结果台词。
- **词/遗物描述**：每件物品一句“谁在什么情况下写下它”。
- **环境**：墙面铭文、被涂改的档案、纸人观众、残碑。
- **Boss 阶段**：每阶段一句台词，揭示 Boss 与昌子的关系。
- **结局**：不解释所有谜题，只回收人物弧光。

## 后续可扩展（不在 1.0 主线）

- **守钟人**：局外成长/重置的拟人化，解释“为什么死了还能再来”。
- **无舌抄写员**：出售禁词，要求玩家用“一段记忆”交换。
- **织录者**：把词缝进装备，做词条重铸。
- **低语之母**：可选 Boss/交易对象，污染源之一。
- **隐藏结局“换位”**：保留特定词并击败笑面史官，昌子与笑面史官互换身份。

## 写作纪律

1. 不写“设定讲解”，只写人物在具体时刻的选择。
2. 每个 NPC 都要有一件不愿提的东西。
3. 每个 Boss 都要是昌子某种可能性的投影。
4. 结局不靠最后按钮，靠沿途的仁慈、污染、焚毁与理解。
5. 留白比解释重要；玩家能自己拼出的部分，不要替他们说完。
