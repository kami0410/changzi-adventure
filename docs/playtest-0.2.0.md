# 昌子大冒险 0.2.0 试玩说明

Windows：双击 `build/windows/changzi-adventure.exe`。原有本地档案会继续保留。

从 Hub 右侧传送门按 E 出发。A/D 移动，空格跳跃（短按小跳、长按高跳），按住 J 连续攻击，L 翻滚，1/2 切换武器，Q/F 使用短语。Tab 打开背包，C 打开造句台，Esc 返回或暂停，F10 设置。结算后按 R 或点击按钮回档案馆。

## 这一版的主要变化

- 进入房间后才锁门，清空后开门并三选一奖励；初始只有六个基础词与局外解锁词，不再开局携带所有遗物。
- 普攻、短语、回墨与遗物构成循环：每秒回复 2 墨，击杀回复 8 墨；新遗物会实际改变冷却、吸血、续命、减速、回复或污染构筑。
- 武器继承 Hub 基底升级；奖励武器还按清房进度提高伤害。
- 跑步腿部交替、跳落地姿态、攻击动作与斩击、翻滚、受击、死亡、NPC 待机；角色高度约 110 像素，地面上移给底部 HUD 留空间。翻滚可穿过敌人，仍受地面和房门约束。
- 背景按比例显示，远景视差、中景柱廊、纸页、尘埃和雾独立运动；屏障改为流动的墨线。
- 远程敌人的墨弹可以躲避；Boss 有三阶段、弹幕与落墨预警。
- HUD 显示当前武器、技能冷却与墨耗、区域目标和清房进度；背包/造句/设置暂停战斗，Esc 或按钮关闭。
- 造句预览显示词条效果，支持键盘选择按钮；结算和暂停菜单可以返回 Hub。

## 试玩重点

1. 从入口走进第一间战斗房，观察门是否只在身后关闭。
2. 试试按住 J、短跳、翻滚与 Q/F 的衔接，留意怪物前摇是否看得清。
3. 清房选择遗物后，在背包查看效果；获得新词后按 C 造句并装备。
4. 进入呼吸废墟后的首次致命伤害应触发续命。
5. 若遇到卡住、打不到、界面挡人或文字看不清，记录所在房间与动作。

## 当前范围

这是双生态区、四房间、一个 Boss 的试玩迭代。角色动作采用现有图的分层程序动画，尚不是完整手绘逐帧图集；四个生态区、多 Boss、多结局与正式音频仍待制作。Android 提供 debug APK，真机触控与性能仍需设备验证。
