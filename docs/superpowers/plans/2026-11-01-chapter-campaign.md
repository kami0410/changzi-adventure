# 昌子大冒险 0.3：三章冒险与表现提升

用户反馈：没有明显 bug，但表现薄、内容少、不知道目标、流程短、没有专属图标。已授权直接改进，核心设计与实现由主控亲自完成。

## 体验目标

从标题开始明确身份和任务，Hub 交代失踪名册，出发后始终知道当前节点要做什么。三章各六个连续横版节点，交替战斗/事件/交易/休整/精英/Boss，章节通关前有台词，之后有记忆回收与地图过渡。一次通关产生完整故事结果，永久保留发现的档案与结局。目标初次游玩约 15–25 分钟，是设计目标而非已测时长。

## 结构

- 第一章 墨雨档案馆：教学战斗 → 倒塌阅览室事件 → 交叉火力 → 旅行商人 → 双波精英 → 墨骸史官。
- 第二章 呼吸废墟：追猎战斗 → 旧日见证事件 → 高低差混战 → 休息与交易 → 冲锋精英 → 肺钟守卫。
- 第三章 无光海：漂流记录战斗 → 最后的读者事件 → 波次封锁 → 决战前休整 → 失忆回声 → 笑面史官。
- 每章额外 2 处可攀平台上的可选记忆碑/宝箱，E 交互；明确主路箭头、房间标题、目标距离。
- 事件选择影响污染、构筑、记录/自由倾向，最终以累积状态决定复原/焚毁/深渊三种结语；明确不把它称为 GDD 全量多结局成品。
- 三章共享角色控制，独立调色、景物、危险与敌人组合；清房保留构筑，不强制每房弹长文本。

## 实现单元

`CampaignData` 静态章节/节点/台词/奖励数据；`JourneyState` 本局章节、节点、事件、档案与结局逻辑；`CampaignWorld` 构造当前章节连续地图、平台与节点标志；`StoryOverlay` 标题/章节/事件/交易/手记统一呈现；game.gd 负责接线。Profile 向后兼容增添故事发现/结局/完成次数。

表现：章节字幕、任务卡与手记、机关灯、动态雾/海面/远景、Boss 登场和阶段反馈、分区环境音乐变化。添加原创标题背景与图标，导出 Windows ICO/Android PNG。

## 美术合同

沿用午夜蓝 #08131b、青绿 #6fc7c1、骨白 #e4dcc0、干血红 #9d3345。图标中心破碎发光书卷+单眼封印，大轮廓，32px可读，无文字；生成1024正方形后规范化到512 PNG/多尺寸ICO。无光海背景1536×864、侧视、前景无角色/文字/碰撞假平台。Boss 从已批准笑面史官像素概念生成透明全身图，256×256底边对齐。生成原稿保留concept，成品记录来源和尺寸。

## 实现状态（2026-11-01）

已落地：三章各 3 房（2 战斗 + 1 Boss）、3 个 Boss、章末剧情与二选一、5 种结局、可选残碑、36 词、8 种法术形态、标题与专属图标、无光海背景、法术/召唤/持续区域表现。验证见阶段记忆与 `docs/playtest-0.3.0.md`。尚未落地：独立逐帧图集、第二章 Boss 独立造型、正式音频、Android 真机。

## 验证

章节/节点数量及Boss顺序测试、事件资源不透支且不可重复领取、手记退出恢复原暂停态、波次完成无假清房、可选路径可达（主角跳高约92px，层高≤70px）、三章通关及三种结语分支、旧存档兼容、标题/Hub/事件/手记/海面/Boss截图、Windows/Android图标与导出验证。计时不以直接杀怪的测试代替真实试玩。
