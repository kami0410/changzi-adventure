# 昌子大冒险 0.5.0 深度版

Windows：`build/windows/changzi-adventure.exe`；Android：`build/android/changzi-adventure.apk`（debug，未真机验证）。

## 这一版加的是什么

### 1. 言出法随 v2：能解释的推演

输入一句话后，界面现在会显示：

- **识别**：这句话里有哪些你已经拥有的词。
- **借用未收录**：哪些词义你还没有真正拥有，只是借用了它的回声；每个借用会带来污染、降低稳定度。
- **意图**：范围 / 连续 / 迟滞 / 治愈 / 护盾 / 吸取 / 献祭 / 自身 / 周围。
- **形态与稳定度**：这句话最终凝成哪一种法术，以及有多稳。

例子：

- `让雷落在火里`：借来“雷”，保留“火”，形成连锁雷 + 雷火共鸣，但污染上升。
- `把记忆烧成回声`：记忆、燃烧、回声三层词义叠成召唤/焰系法术。
- `让时间停下来`：时间 + 迟滞意图，形成时渊。
- `治愈自己`：生命 + 自身目标，形成护写。
- `不可名状的低语`：没有识别到已知词义，生成一个确定性的“未名之词”，仍可装备施放，但更不稳定。

输入框下面有三个示例按钮，点一下就能看到完整推演。未来接入 AI 时，AI 只解析意图，数值仍由本地规则钳制。

### 2. 第四章：笑面剧场

四章主线现在是：

1. 墨雨档案馆 → 墨骸史官
2. 呼吸废墟 → 肺钟守卫
3. 无光海 → 最后的读者
4. 笑面剧场 → 笑面史官

第四章有独立的程序化舞台：红帷幕、观众席、纸人、聚光灯、断吊灯、脚灯；最后的读者与笑面史官是两个不同 Boss。剧场背景目前是程序绘制 + 档案馆底图调色，**不是新生成的专属插画**（Magpie 图像额度到 15:39 UTC+8 才恢复），额度恢复后会替换。

### 3. 残页与局内商店

- 击杀、清房、Boss 掉落“残页”；HUD 显示。
- 每章一个纸人交易所，按 E 打开：恢复、遗物、新词/武器，用残页购买。
- 商店是单局内的构筑选择点，不消耗局外记忆碎片。

### 4. 难度与可访问性

- 标题界面新增“梦魇旅程”：敌人生命/伤害提高，残页与局外奖励更多。
- 设置（F10）新增“减弱屏幕震动”“减弱闪屏”，并写入 Profile。
- 语言图鉴显示“词表 x/50”，残碑、商店、章节选择共同构成局内成长；推演器额外认识冰、风、光、影、梦、星、镜、歌、遗忘、神圣、漆黑、双生等概念，未拥有时可借用。

### 5. 音频

新增第四章剧场配乐与最后的读者/第四章旁白，共 6 首循环配乐、22 段中文旁白。

> 配音仍是 Windows SAPI Huihui 原型；正式商用需替换为真人或有商用授权的 TTS。配乐为程序化合成，可替换同名 OGG。

## 试玩重点

1. 在语言图鉴输入“让雷落在火里”“把记忆烧成回声”“让时间停下来”，看“识别/借用/意图”是否符合你的预期。
2. 故意输入一句没有已知词的话，确认仍能施放、但更不稳定。
3. 打第四章：先遇最后的读者，再进剧场见笑面史官；看程序化舞台是否成立。
4. 用残页在商店买遗物/新词，观察构筑变化。
5. 开梦魇旅程，确认敌人强度与奖励差异。
6. 在设置里打开“减弱震屏/闪屏”，确认生效。

## 仍然不是完整商业版

- 第四章专属插画、最后的读者/LoB 的独立立绘尚未生成（Magpie 额度限制）。
- 配音为 SAPI 原型；配乐为程序合成。
- 没有独立手绘逐帧图集。
- Android 未真机验证。
- 商店/事件目前是每章一个，还没有完整的节点地图与分支路线。
