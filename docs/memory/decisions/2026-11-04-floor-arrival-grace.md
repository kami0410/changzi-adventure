# 地面门到达宽限（floor arrival grace）

- 日期：2026-11-04（第 36 程）
- 状态：已实施（MDS 插件内最小改动，`floor_arrival_grace` 可关）

## 背景

MDS 世界用门（`MDSGate`）连接房间。门可位于房间的 `left` / `right` / `top` / `bot` 边。`bot` 门在可走地面上，玩家从该门进入下一房间时，MDS 把到达点放在门上方，并给一个向上的出速 `up_exit_speed`（默认 650 px/s），让玩家越过门洞、落到门旁地面，而不是直接掉回洞里。

第 2 章大地图验收发现：从 `bot` 门到达后约 0.7 秒，玩家会在落地时再次进入同一扇门的触发区，被送回上一房间。所有向上纵向连接因此在实践中变成单向。原有保护只有「到达后 3 个物理帧忽略门」+「门冷却 0.35 秒」，覆盖不了整个抛物线。

## 决定

在 `addons/MetroidvaniaDeveloperSystem/nodes/mds_world_game.gd` 增加最小、显式的到达宽限：

- 新增 `@export var floor_arrival_grace := 1.2`（秒）。0 表示关闭，行为回到旧版。
- `load_room()` 记录本次到达门 `_arrival_gate`；仅当 `world.get_gate_side(id, entry_gate) == "bot"` 时设置 `_arrival_grace_until = now + floor_arrival_grace`。
- `_on_gate_entered()` 在原有 `changing_room` / 冷却 / 3 帧保护之后，若触发来自本次到达门且仍在宽限期内，直接返回。
- 横向（left/right）与 top 到达不设置宽限，行为不变；没有 bot 门的世界完全不受影响。

## 为什么改插件而不是在游戏层绕过

- 缺陷在 MDS 的到达/触发语义里，不在第 2 章内容里。游戏层可做的绕过（到达后强移玩家、临时禁用门节点、在门下加平台）都会把引擎行为写进章节内容，影响所有 bot 门，且更容易与存档/续玩冲突。
- 改动是**追加式**的：新增导出字段 + 两个私有字段 + 两个判断，不重写门/房间/存档逻辑；默认 1.2 秒，`0` 可完全关闭。
- 插件为仓库内 vendored 代码（非 submodule），第 1 章世界没有 bot 门；第 3/4 章世界核查无 bot 门。因此实际行为变化只发生在第 2 章的纵向门。

## 后果

- 第 2 章所有 bot 门到达不再回弹；玩家可在门旁稳定落地，再主动走回门里仍可正常返回（宽限期过后）。
- 故意在 1.2 秒内再次穿过同一扇到达门会被忽略；这是有意的取舍，正常游玩不会触发。
- 新增集成断言：`ch2_entry` bot 到达后 2 秒仍在原房间；25 段门行走全部走通。
- 未改门冷却、出速、门位或其他 MDS 语义；未新增移动能力。

## 红线

不改 MDS 的房间/存档/世界格式；不改玩家战斗/移动参数；不开放第 2 章可达性；不把该宽限扩散到横向/top 门。
