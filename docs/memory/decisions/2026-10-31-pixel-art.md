# ADR-0001：高精度像素美术

## 状态

已接受（2026-10-31，用户选择像素版）。

## 决策

- 纯像素美术，不做手绘/厚涂生产管线。
- 高精度像素 + 动态光影、粒子、着色器提升质感。
- 初稿规格：角色 96×96、Boss 256×256、tile 32×32、原生 1280×720。
- 调色板：午夜蓝、病态青、骨白、干血红；污染用黑绿/紫黑。
- 手绘风格测试只作为概念参考，不进入正式资产。

## 理由

- 用户明确选择像素版。
- 动画与批量资产成本可控，适合小团队。
- 与《死亡细胞》《以撒的结合》的参考方向一致。
- 像素风更容易统一角色、敌人、道具图标与 UI。

## 后果

- 所有资产必须统一像素密度、调色板、轮廓光与投影规则。
- 生成图只作为草稿；最终 sprite 必须切图、去背、对齐 pivot、检查 alpha。
- 角色立绘/对话头像也用像素风，不混用手绘。
- 需要建立像素资产规范与 QA 清单。
