# UI 视觉方向（0.9）

## 设计意图

主角是失忆的宇宙史官，世界是被记录吞掉的档案馆。UI 不做“暗色科幻面板”，做**档案卷宗**：
每个窗口是一页被归档的纸页压在墨色桌面上；标题像档案编号和朱批，数值像手写的批注。

唯一的大胆处：**纸页**。所有模态窗口是骨白偏暗的纸页（低饱和、暗部压住），四角带墨渍压角；
HUD 不用纸页，只用墨色衬底，保持战斗画面干净。其他一切保持安静。

避免的模板痕迹（frontend-design 技能列出的默认做法）：
- 不用全大写英文小标题（ARCHIVE SUSPENDED、GURU'S STALL）；标题上方不加装饰性标签。
- 奖励卡不用 01/02/03 编号（不是顺序关系）；用类别名。
- 不用“A · B · C”中点串当说明；改成完整短句或分行。
- 不是所有东西都套同一种圆角卡片：纸页、墨条、印章三种层级各有形状。

## 配色令牌

| 名称 | 值 | 用途 |
|---|---|---|
| 墨夜 ink_night | `#0d1218` | 桌面/遮罩底色（压暗场景 82%） |
| 旧纸 paper | `#c9bfa6` | 模态纸页底色（再乘 0.92 压暗） |
| 纸影 paper_shade | `#9c917a` | 纸页暗边、分隔线 |
| 墨字 ink | `#1b1f24` | 纸页上的正文 |
| 朱批 cinnabar | `#a8322e` | 纸页上的标题、危险、焦点框 |
| 病青 cyan | `#8fe8dc` | HUD 文字强调、可交互提示、轮廓光（与角色边光一致） |
| 骨白 bone | `#e8e1cf` | HUD 正文 |
| 苔金 gold | `#d8b46a` | 稀有/传说、货币（残页、记忆碎片） |

纸页上文字是深色（墨字/朱批），HUD 上文字是浅色（骨白/病青），两套不混用。正文对比度 ≥ 4.5:1。

## 字体与字号

- 字体：Fusion Pixel 12px Monospaced zh_hans（Ark Pixel 的补字缝合版，OFL），只用 **12 / 24 / 36 / 48**，其他字号会糊。2026-11-02 从 Ark Pixel 切换，解决 25 个缺字。
- 12：说明、数值、按键提示；24：标题、按钮、HUD 主数值；36：窗口大标题；48：标题画面。
- 正文行长 ≤ 36 个汉字；纸页正文行距 +4。

## 面板与按钮

- **纸页**（模态窗口）：旧纸底、2 px 纸影边、外加 2 px 墨色描边（纸压在墨上）、无圆角、阴影 6 px 偏右下。
- **墨条**（HUD 衬底）：墨夜 85% 不透明、1 px 病青 30% 上边线、无边框。
- **按钮**（纸页上）：透明底 + 1 px 墨字边；悬停/焦点：朱批 2 px 边 + 纸色加深；按下：下移 1 px。
- **焦点**：朱批 2 px 外框，任何时候可见（手柄可用）。

## 层级

- 模态打开时：遮罩墨夜 82%，**隐藏 HUD**；同一时间只显示一个模态。
- AI 设置、NPC 言灵等弹窗必须在 Hub 顶栏之上（CanvasLayer ≥ 50）。

## 文案

- 动作按钮写清会发生什么：“继续”“装备到 Q”“离开交易所”。同一动作全程同名。
- 错误说明原因和解法，不道歉：“残页不足：还差 6 页。继续战斗会掉落残页。”
