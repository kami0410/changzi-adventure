# ADR：1.1 的设计决策

1. **AI 的权限是一张动词表，不是脚本**：AI 只能从 `WorldActs.ACTS` 里选动词并填参数，客户端按表校验；不执行任何 AI 给出的代码或节点路径。加权限 = 往表里加动词 + 一个处理函数 + 测试。
2. **强度不封顶，数量封顶**（沿用 1.0 第 5 条）：伤害、倍率、时长都不钳制；只限制会拖垮帧率的东西（动作 / 规则 / 召唤 / 平台的个数、规则最小间隔、嵌套层数）。
3. **规则是数据**：`{when, do, seconds, times, interval}`，由 `game.gd` 在对应时机调用 `world_acts.trigger()`；规则里的动作再触发规则时计嵌套层数，超过 2 层丢弃，防止自激。
4. **全局倍率只走 `WorldActs` 的 modifier**（重力、敌人速度 / 伤害等写到 `Enemy` 的静态量与玩家的 `word_*` 量），离开 run 场景时复位；不直接改 `RunMutators`。
5. **友方召唤不算击杀、不触发房间结算**；敌方召唤进当前房间的敌人表，友方只挂在 `_word_room`。
6. **Boss 保护**：抹杀对 Boss 改为扣比例，变形对 Boss 无效；其余动作照常。
7. **开口即言灵不占短语位**，暂停世界、按句子分量收墨，最短间隔 1.5 s；AI 回复迟到（玩家已关闭输入条）则丢弃。关闭只认 `ui_cancel`，因为暂停键是可能被打字用到的字母。
8. **世界状态进局内存档**（`world.word`：倍率、限时效果、规则、写出的遗物规则）；读档时过一遍 `sanitize`。
9. **AI NPC 的祝福与记忆存 Profile**（祝福 ≤ 3 条、记忆 8 句），开局一次性消费。
10. **Magpie 动作表管线**：原始 4×6 表留在 `assets/concept/magpie/`，只经 `tools/import_magpie_sheets.py` 进入 `assets/sprites/creatures/`；以游戏内原立绘作参考图，缩放到原立绘身高、每行统一脚线，碰撞体不变。测试按 `CreatureArt.art_key()` 比较美术，不比较文件路径。
11. **画质是一个开关**（`Perf`）：逐帧表现代码只读 `Perf.low` / `fx_cap` / `ambient_scale`；自动档 = 手机流畅、桌面完整。新加的表现层都必须在 `Perf.low` 下成本不变或更低。
12. **角色着色器不再乘 `COLOR`**：canvas_item 片段里 `COLOR` 已经是「顶点色 × 贴图」，调色经 varying 传入。以后改 `pixel_smooth.gdshader` 不要恢复 `texture * COLOR`。
13. **可读性分层**：背景（z ≤ -3）→ 纵深雾（z -2）→ 地块与顶边 → 角色（按身份描边）→ HUD。新背景 / 中景不要放到 z -2 以上。
14. **HUD 是墨、弹窗是纸**（沿用 UI 方向 ADR）：战斗中出现的控件（输入条）用墨底样式，不能直接套纸面主题的按钮。
