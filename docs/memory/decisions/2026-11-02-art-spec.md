# 像素美术规范（0.9）

承接 [ADR-0001 高精度像素美术](2026-10-31-pixel-art.md)。本文件是技术合同：生成图、规范化脚本和渲染代码都按它检查。

## 诊断（2026-11-02）

- 贴图 PNG 本身是干净像素：0.7 的角色 15–25 色、透明边干净。
- **游戏里发糊来自渲染**：一个 NPC 截图区域约 5000 像素里出现 3100+ 种颜色。原因：
  1. `ActorMotion` 把贴图切成头/躯干/腿，按非整数比例缩放、旋转、非等比挤压后用最近邻采样，像素被拉成不等宽、边缘锯齿闪烁；
  2. 角色缩放 1.05/1.1/1.2/1.3/2.15 等非整数倍；
  3. 窗口 `canvas_items` 拉伸再放大一次；
  4. 0.8 补的 9 张图（last_reader、smiling_archivist、choir_summoner、ink_bomber、mask_enemy、seat_husk、page_swarm、baiyu、wenjin、mirror_sniper）没有量化：数百到 1.7 万色，本身就软。
- **浮空**：`Sprite2D.offset` 在贴图空间（先于 scale），代码当成屏幕空间算；贴图底部透明行没算；阴影少乘 scale。见 [issues](../issues/2026-11-02-sprite-float-blur.md)。

## 规格

| 类别 | 画布 | 屏幕显示 | 调色上限 | 备注 |
|---|---|---|---|---|
| 主角 | 96×96 | 1× 原生（约 92 px 高） | 24 | 底边脚底对齐 |
| 普通敌人 | 96×96 | 1× | 24 | 飞行单位脚底不贴地，按设计悬空 |
| 精英/大型敌人 | 128×128 | 1× | 32 | 错字巨兽等 |
| NPC | 96×96 | 1× | 24 | Hub 里站在地面线上 |
| Boss | 256×256 | 1× | 40 | 第二章肺钟守卫要专属图 |
| 武器图标 | 64×64 | 1× / 2× | 16 | |

- **只允许整数缩放**（1×、2×）。要更大就按目标画布重新出图，不在运行时放大。
- **透明**：alpha 只有 0 或 255；不允许半透明羽化边（光晕用代码画）。
- **轮廓**：1 px 深色外轮廓（墨黑 `#0b0f14` 一类的暗色，不是纯黑），右上青色轮廓光 `#8fe8dc`。
- **脚底**：最低不透明行 = 画布最后一行（底边对齐），水平按不透明区域居中。
- **调色角色**：午夜蓝（阴影/布料）、病态青（轮廓光/魔法）、骨白（纸、骨、面具）、干血红（内衬/危险）、墨黑（轮廓/墨），污染用紫黑/黑绿。

## 渲染规则

- 角色贴图用 `pixel_smooth` 着色器（逐像素采样纹素中心，只在纹素边界做 1 px 过渡），过滤设 LINEAR：任意缩放、旋转都不会出现不等宽像素。
- 程序动画只做**整体**的位移、挤压（以脚底为轴）和轻微倾斜；不再切块旋转腿和头（会撕开像素）。
- 阴影画在脚底所在的 y；挤压以脚底为轴，落地时脚不离地。
- 文字只用 12 的整数倍字号（12/24/36/48）；Ark Pixel 12px 在其他字号下笔画粗细不均。

## 规范化流程

`tools/normalize_sprite.py`：源图 → 去背（只取 alpha）→ 按目标高度最近邻缩到画布 → 中值色块合并去伪像素 → 量化到调色上限 → 1 px 轮廓 → alpha 二值化 → 底边居中 → 写入 `assets/sprites/` 并记录到 `assets/asset-manifest.json`。
