# ADR：1.0 正式版的设计决策

1. **美术包只经 `tools/import_art_pack.py` 进入 `assets/`**：交付原图留在 `art_inbox/`（原始生成图不入库）；重导入即重跑脚本。玩家动作统一到约 93 px 身高。
2. **生物怪按状态切条**（`CreatureArt.pick()`）：死亡 > 攻击（`creature_phase`）> 受击 > 移动 > 待机；`death_delay = 死亡条时长 + 0.25 s`；`frame_animated` 敌人不再套用通用暗红塌缩。
3. **交付地块修复后采用**：去 1 px 描边、两行都补亮顶边、平台板加厚到 16 px；第 2/3 章填充做半混合中值柔化，防止 16 px 点阵。
4. **中景层 ×(0.64, 0.66, 0.74)**：原画中景与前景同等精细，必须压暗才能保证平台/角色可读。
5. **言灵权能数值不设上限**，代价由墨耗/冷却/污染承担；只限制实体数量（改写敌名 ≤ 8、墨阶 ≤ 12 级、瞬移 ≤ 4000 px）。Boss 不可被改写，处决对 Boss 只扣比例 ×25%。
6. **AI 化身 NPC 的效果不受离线上限**（折扣仍 ≤ 0.35），新增赠礼走 `ai_*` pending 键；离线关键词保留上限，避免离线刷取。每 NPC 每次回 Hub 一次不变。
7. **法典跨「新游戏」保留**：它是玩家写下的句子，与按键/无障碍设置同类。
8. **章节异象由「种子 + 章节」决定**，不存档、不占 run RNG；验收套件关闭 `Flow.encounter_variation` 时一并关闭。
9. **每日挑战种子 = hash(本地日期)**，run save 记 `daily` 布尔。
10. **转场只换视觉不换时序**：墨晕着色器读 MDS 淡入淡出矩形的 alpha，任何等待淡入淡出的代码不受影响。
11. **战斗层**：同长度同速度的 `<track>_combat.ogg` 与主曲同时启动；追击中的普通敌人在 1000 px 内即进入战斗，脱战保持 4 s 后淡出；Boss 用独立 Boss 曲。
12. **闻烬/白榆在 `Profile.demo_cleared` 后登场**，与五位 NPC 的个人事件同一闸门；不改其设定与职能。
