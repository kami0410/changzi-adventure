# 0.6.0 AI 言灵

## 本轮落地

- **AIService 自动加载**：读取 `user://ai_config.cfg`；Ollama / OpenAI 兼容 / Anthropic 三种请求；HTTPRequest 超时、缓存、单请求锁；`intent_ready/intent_failed/status_changed` 信号。
- **AI 只解析意图**：`build_request` 使用固定 system prompt；输出经 `validate_intent` 的形态/词义白名单、名称/描述长度、组件数值钳制；`SpellSynthesizer.compile_intent` 再走本地编译，`PhraseCaster` 不变。
- **UI**：语言图鉴增加“AI 解读”按钮与状态；F10 → AI 言灵设置（启用/服务/接口/模型/密钥/超时/测试）；未配置时提示离线推演。
- **隐私**：只有点击才发送；句子 `< >` 转全角；密钥只在 `user://`，不打包；不自动装备；同一句会话内缓存。
- **Android**：导出预设加 INTERNET 权限。
- **测试**：`test_ai.gd`（三种请求、响应解析、非法形态、名称截断、伤害钳制、配置读写）、`test_freeform_synthesis`（AI 意图编译）；全量 1909 passed；四章流程 70 checks；成品包 71 checks。
- **包体**：Windows 110.09 MiB、Windows ZIP 44.01 MiB、Android 39.31 MiB；APK 0.6.0 / arm64 / INTERNET 权限 / 图标与 v2+v3 签名通过。
- `AIService` 设为 `PROCESS_MODE_ALWAYS`，因为语言图鉴/设置会暂停场景树，HTTP 回调必须继续跑。

## 环境事实

- 本机 **没有 Ollama**，`ANTHROPIC_API_KEY`/`OPENAI_API_KEY` 未设置；因此没有做真实联网调用，不能宣称线上模型质量/延迟已验证。功能按“可选”交付，默认离线。

## 使用

见 `docs/ai-skill-hook.md`：Ollama 默认 `http://127.0.0.1:11434/api/chat` + `qwen2.5:7b`；OpenAI 兼容接口可指向 LM Studio/vLLM/代理；Anthropic 默认 `claude-opus-5-5`，需密钥。
