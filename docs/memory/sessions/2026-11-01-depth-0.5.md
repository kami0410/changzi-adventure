# 0.5.0 深度版

## 背景

用户要求“继续深度优化，现在离完整版还差很多”，并特别强调“言出法随一定要做好，这会是一个非常有趣的点”。本轮优先把言灵做成可解释、可借用、可测试的核心系统，同时补第四章、局内经济与可访问性。

## 本轮落地

- **言灵 v2**：`SpellSynthesizer` 拆成“已拥有词 / 借用未收录词义 / 意图修饰”三层；UI 显示识别、借用、意图、形态、稳定度；未收录词义借用时带污染、降低稳定度；输入框三个示例；`explain()` 输出推演理由。可收集词扩到 50（冰/风/光/影/梦/星/镜/冻结/歌唱/遗忘/巨大/神圣/漆黑/双生），推演器另认 20+ 概念别名。
- **第四章**：笑面剧场（程序化红帷幕、观众席、纸人、聚光灯、断吊灯、脚灯）；boss 为笑面史官。第三章新 Boss「最后的读者」（`last_reader.gd`，回声造型、读页封印/镜像弹幕/落墨），原第三章的笑面史官移到第四章。
- **残页经济**：`RunState.pages`；击杀/清房/Boss 产出；每章一个 `MemoryShop`，E 打开 `RunShopUI`，可买恢复/遗物/新词/武器。
- **梦魇难度**：标题界面开关；敌人生命 ×1.35、伤害 ×1.3，残页/局外奖励增加。
- **可访问性**：设置里减弱震屏/闪屏，写入 Profile；`Player`/`ScreenFX` 读取 `Flow.shake_scale/flash_scale`。
- **音频**：第四章 `chapter_theater.ogg`；`ch4_intro/outro`、`boss_reader_phase2/3`；共 6 首配乐、22 段旁白。
- **测试**：`test_shop`、`test_freeform_synthesis` 扩展、`test_campaign` 四章、集成 70 项。
- **Magpie 限制**：图像额度到 15:39 UTC+8 才恢复，第四章专属插画/最后的读者立绘未生成；用程序化舞台 + 现有角色资产变体，不谎称已生成。

## 已知限制

- 第四章专属背景/最后的读者立绘未生成（Magpie 额度）。
- 言灵目前是规则推演，不是 LLM；AI 钩子只做意图/数值钳制。
- 商店是每章一个固定交易所，没有完整节点地图/分支路线。
- 配音仍是 SAPI 原型；配乐为程序合成；独立手绘逐帧动画未做。
- Android 未真机验证。
- 退出时仍有少量 Godot 清理警告（测试/场景立即退出），不影响运行。
