   重建后把焦点还给同一词的新按钮。手柄集成 109 → 112。暂停菜单原生确认框在 headless

4. **局内获得新词性能**（临时基准 `tests/bench_codex_acquire.gd`，测完删除）：
   - 方法：真实 `main.tscn` 首房，热身 2 词后连续 `_acquire_word` 24 个未拥有词，
     每次采样之间 `await process_frame`；按 20→32、32→44 词分两段，另测隐藏图鉴/
     背包/HUD 刷新与图鉴首次打开。
   - 基线（44 词）：拿词 median 1406.8 ms（32→44）/ 950.9 ms（20→32）；隐藏图鉴
     词卡重建 920.3 ms、组合卡 74.9 ms；隐藏背包 586.0 ms；首次打开 1.86 ms。
   - 修复：`CodexUI` / `InventoryUI` 词卡按 `word.id` 缓存并原地增量更新；换绑另一局
     时清空重建一次；`_refresh_combos()` 加组合指纹，组合未变不重建。只改刷新方式。
   - 结果：拿词 median 35.4 ms / 35.5 ms（约 -97.5%）；隐藏图鉴 0.67 ms、背包
     0.61 ms；首次打开 1.67 ms，未把开销挪到首次打开。单元 +6 锁行为。
