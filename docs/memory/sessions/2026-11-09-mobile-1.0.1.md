# 2026-11-09 · 1.0.1 手机可玩

用户指出 1.0.0 安卓没有可用触控、屏幕适配有问题，并要求一并加二段跳、解决"平台离地太近怪会卡住"。

## 反思（根因）

- 0.11 留下的触控是普通 Button：单触点（无法边走边跳）、只挂在战斗场景（Hub 走不动出不去）、没有"下"、压住底部 HUD；1.0.0 从未在触屏上验证就在发布说明写了"可直接安装"。
- `scale_mode="integer"`：1080p（1.5 倍取整为 1）和手机上逻辑画面变成物理分辨率，界面缩小、视野变大；测试和截图一直固定 1280×720 窗口，所以没发现。

## 做了什么

- **缩放**：`scale_mode` 改为按比例（Godot 默认值，project.godot 不再写此键）；第 1 章 `MDSChapterRoom.SIDE_BLEED` 与 Hub 背景/地面向两侧延伸，宽屏不露灰底。
- **触控** `scripts/ui/touch_overlay.gd`（Flow 持有的 CanvasLayer 15）：浮动摇杆 + 圆形按键，`_input` 按 `InputEventScreenTouch.index` 追踪；动作经 `Input.parse_input_event(InputEventAction)` 发出（页面用 `_unhandled_input`，玩法轮询）；Hub 只给 跳/交互 与 图鉴/说明/设置（按脚本路径识别 Hub，避免 Flow 循环依赖）；菜单行跟随左上信息面板底边；按设备与暂停/玩家冻结自动显隐。旧 `touch_controls` 删除。
- **设备与提示**：`Flow.using_touch`（真触点开启；键盘、实体鼠标、手柄关闭；模拟鼠标 device -1 忽略）、`TOUCH_LABELS`、`close_prompt()` → "点按"；HUD 触屏布局把卡片移到顶部；对话/剧情/奖励页触屏下去掉键位提示；设置页加 触屏按键 自动/始终/隐藏、大小、透明度（`Profile.touch_*`）。
- **二段跳**：`Player.air_jumps`/`double_jump_velocity`/`can_double_jump()`；平台地块上 下+跳 落下（`standing_on_one_way_tile`，短暂关闭地形碰撞并冻结水平速度）。
- **平台**：四套地块的平台瓦片 `one_way = true`；`CollapsingPlatform` 与非电梯 `MovingPlatform` 单向；第 1 章平台行 27/24；`RoomVariety.RISE` 112–144。

## 验证

- 单元 14,424 / 0；新集成 `integration_touch`（30 断言：Hub 摇杆行走、摇杆+跳同时、二段跳、滑动换键、按键在屏内、菜单开页并隐藏、设置隐藏、HUD 布局切换）；其余 11 套见发布说明。
- `tests/capture_touch.gd` 在 2400×1080 / 1920×1080 / 1280×720 / 2560×1600 截图核对布局。
- 雷电模拟器（2560×1440，adb `D:/Android/Sdk/platform-tools/adb.exe`）：安装、标题页、Hub 摇杆行走、跳跃、传送门进第一章、战斗布局均正常；adb 只能模拟单指，多指由集成测试覆盖。
