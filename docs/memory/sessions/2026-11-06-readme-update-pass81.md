## 复原可达性（代码 + 测试）

- `_apply_chapter_choice` 把章末选项的 `mercy` 累加到 `_mercy`（第 1/2/3 章选项 0
  各 +1）；`_mercy` 是成员变量，`_start_chapter` 不重置，并写入 run save 的
  `"mercy"` 键。
- 第 3 章章末 `_finish(true)` 调
  `CampaignData.ending_for(true, corruption, _mercy, _burned_final)`。
- `ending_for` 顺序：失败 → `interrupted`；`burned` → `burned`；污染 ≥ 60 →
  `abyss`；仁慈 ≥ 2 → `restored`；否则 `unfinished`。
- `tests/test_campaign.gd::mercy_restores_archive` 锁定
  `ending_for(true, 10, 2, false) == restored`。
- 因此第 1–3 章中任意两章选择仁慈选项（跨章仁慈 ≥ 2）且结束时污染 < 60，即可在
  第三章末拿到「复原」；`_burned_final` 只在第 4 章选项 1 置位，所以「焚毁档案」
  仍不可达成。「深渊回响」（污染 ≥ 60）、「未完的注脚」（其余通关）、「记录中断」
  （失败）均可达成。
