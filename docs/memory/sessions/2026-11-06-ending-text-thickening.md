## 圣经依据

来源：`docs/story-bible.md`。

- 五个结局的触发、内容与余味：`## 结局` 下「复原 / 焚毁档案 / 深渊回响 /
  未完的注脚 / 记录中断」五节。
- 五名 NPC 的秘密、弧光、关键道具与「结局后」：`## 四位同行者 / 五位 NPC`
  下陆沉/阿砚/咕噜/闻烬/白榆五节。
- 笑面史官身份：`## 反派：笑面史官`——「未来的昌子，或者说，是昌子所有可能
  版本中『最会写结局』的那一个」；「最终揭示：他的脸后面不是脸，是一页写满
  『昌子』的名字的纸。每一个名字都是一次失败的重来。」
- 最后一页：第三章节拍「他交出空白的最后一页，并说『故事需要有人翻页』」；
  笑面史官目标「让昌子回到舞台上，替自己完成最后一页」；深渊结局「昌子写下
  最后一页时，墨自己动了起来」。

两处母题圣经都有明确定义，没有缺口；回收段只使用上述定义，不新增身份或
最后一页的内容。

## 余味与回收段（摘要）

- 复原：陆沉交出红色文件夹、阿砚的炉子不再熄（不写未实现的真名/出铺分支）、
  咕噜「这个不卖，借你」且瓶子空了、闻烬重写自己的名字、白榆的地图多一条路。
- 焚毁档案：五人分别面对「世界失去历史」——文件夹留在观众席、断页剑烧掉、
  词堆烧空、改过的名字不算数、地图只剩一半。
- 深渊回响：五人分别面对「昌子成为污染的一部分」——读不懂昌子的句子、
  认不出推门的人、对着一团墨讲价、改不回被污染读过的字、每条路都通向墨。
- 未完的注脚：五人都把未完成的事挂在「那一页空白」上，等一个大概不会来的
  下一次。
- 记录中断：五人都停在「下一次」之前——半页入职档案、关上的炉门、暂时赊账的
  瓶子、没有落下的笔尖、留在出发点的地图。
- 每结局回收段：复原把写满「昌子」的纸合进名册、最后一页没有撕；焚毁把两者
  一起烧掉；深渊由昌子写下最后一页、纸上每个「昌子」都睁眼；未完让最后一页
  继续空着、笑面史官把纸压在名册底下；中断让最后一页没写完、纸上还留空行。

逐句的圣经原文依据见 `SUPERVISOR_STATUS.md`「结局文本加厚（第 66 程）」专节。
