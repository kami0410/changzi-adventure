# 2026-11-08 · 1.0.0 正式版

用户交付全套美术（`昌子大冒险-全套美术素材/`，拷入 `art_inbox/`），并确认「这一版做完之后就是正式 1.0」「力求完整，不要再留口子」；
同时要求 AI 有很大权限、素材库能用的都上、保持并加大肉鸽随机性、把阿砚（熔炉/锻造之神）的立绘换成新画的。

## 做了什么

- **美术接入**：`tools/import_art_pack.py`（二值 alpha、按帧切条、玩家统一身高：空中冲刺 2×、终结重击 0.8×）。
  - 生物怪 10 种 × 6 条动作 → `assets/sprites/creatures/<id>/` + `creatures.json`；`CreatureArt` 重写为按状态选条；`Enemy.creature_phase()`、`frame_animated`（跳过通用暗红死亡）。
  - 区域背景：`tools/build_region_backdrops.py` 改为从 12 张原画合成 27 区（1.25× 放大底部对齐、上方雾化；纵井用 2160 原画）；`RoomDressing.REGION_THEMES` 选中景，中景压暗 `MID_TINT`；删去程序化井壁与 `build_dressing.py`。
  - 地块：交付地块有 1 px 描边接缝、顶边缺失——先判定不可用，用户追问后改为修复采用（去描边、补顶边、平台加厚、第 2/3 章中值柔化）；删去 `build_chapter_tiles.py`。
  - 道具 8 槽/章（GLOWS/SWAY 按新槽位）、电梯轿厢九宫格 + 导轨 + 面板、词缀图标（HUD 提示 + 精英金冠）、标题主视觉、阿砚 128 精灵与 192×256 / 800×1000 立绘。
- **4 新怪**：`BellEnemy`（锈钟兵）、`PageThrowerEnemy`（溺亡书记）、书脊蜈蚣（`ChargerEnemy`）、`PuppetEnemy`（提线笑偶）；新音效 bell_toll / page_fan / puppet_slam；各章 `CHAPTER_CREATURES` 首位。
- **言灵权能** `WorldPowers` + `PhraseCaster.world_power_requested/world_powers_cast` + `game.gd` 的 reveal/unlock/conjure；`Enemy.charm()`（离开 enemies 组、碰撞层 0、追打同类、到时倒下计入清房）；`Player.grant_invulnerability()`。离线 `POWER_WORDS` + 秒数/量词放大；AI prompt 列出全部权能与代价字段；`INTENT_COMPONENTS` 补 `purify`。
- **AI NPC**：`NPCProfiles.apply_effect(..., from_ai)` 跳过离线上限，新增 start_health/start_ink/start_relics/weapon_damage（`ai_*` pending 键，`game._apply_ai_run_gifts` 不封顶）。
- **言灵法典**：`Profile.grimoire`（`[codex] grimoire`）、图鉴「收入法典」与法典按钮行。
- **章节异象** `RunMutators`（8 种，种子+章节）；遭遇变数替换 0.40、词缀 0.45；**每日挑战** `GameFlow.daily_seed()`、标题按钮、run save `daily` 键。
- **转场/质感**：`ink_fade.gdshader`（InkBleed 移植）挂在 MDS 淡入淡出矩形上（alpha=进度，时序不变）；`PaperGrain` 纸纹；补用 status_stunned / spell_poison / status_poisoned / slash_spin，删去 creature_* / soul_rise / thrust。
- **配乐 v2**：`tools/generate_music.py` 重写（名册动机、A/B 段、drone 周期对齐循环、环形混响），新增 hub / ending 与四章 `_combat` 层；`AudioManager` 同步播放战斗层，`game._update_music_layer` 追击时淡入。
- **剧情**：闻烬、白榆通关第一章后在 Hub 登场（`Hub.is_late_npc/late_npcs_arrived`），个人事件「断尖笔」「没有终点的地图」。
- **遗留收口**：全屏跨重启保存（`Profile.fullscreen`）；ui_prompts 的 2 条「环境失败」实为测试读取本机 AI 配置，改为临时配置；GDD §20 八项全部定案。
