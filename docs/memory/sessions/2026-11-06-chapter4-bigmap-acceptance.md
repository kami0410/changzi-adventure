## 逐项结论

1. **连通性**：计划图从 `ch4_entry` 有向 BFS 九区全可达；世界扫描出 22 门 =
   20 扇连通 + 2 扇只到达（`ch4_entry/shortcut_arrival`、`ch4_boss/left1`），
   30 步真实门行走覆盖全部 22 扇；2 扇显式单向语义正确（`elite_boss` 进 Boss
   后 `left1` 无出向转移、`use()` 无效；`hub_shortcut_entry` 带
   `requires = [ch4_shortcut]`，屏障默认封闭）。双向门逐扇校验世界镜像。
2. **边界/相机**：九区每区在真实到达后校验 `MDSBigRoom` 管线、房间边界 =
   计划尺寸、`get_room_bounds()`、相机四边限制 = 世界边界、玩家在房间内、
   区域 = `Smiling Theater`。第 4 章九区均为单矩形
   （`get_local_rects().size() == 1`），没有 `MDSRoomCamera` 分区切换，按现状
   记录。
3. **纵向**：5 台电梯（`branch_b`/`hub`/`vault`/`well`/`elite`）均为
   `MovingPlatform`、速度 = 管线默认 **80 px/s**、行程不越界且完全在房间内
   （只实测记录，未改数值；待确认第 12 项仍只针对第 2 章）；`ch4_branch_b`
   电梯乘行 → top 门 → 跳跃触发 → 到达 `ch4_entry` bot 门（出速 ≤ -600、
   落点在门上方、2 秒内不被同门弹回）；`ch4_well` 下层（2160 高，坠落平面
   2400）不误判坠落，3 个单向落台下+跳可穿下；`ch4_hub` 长椅写入回退点，
   坠落只扣一次伤害并回到长椅。
4. **衔接**：每扇门断言目标/到达门、`changing_room` 期间不弹暂停/剧情/奖励/
   地图/权柄/商店、到达坐标容差（横/顶 3 px、bot 落点窗口）、到达信号一次；
   世界 `seamless_rooms = false`、`fade_time = 0.22`，按既定「门 + 淡入」口径，
   不做无缝走进。
5. **一次性内容**：3 个宝箱（`ch4_vault/Chest1`、`ch4_branch_a/Chest1`、
   `ch4_well/Chest1`）与 2 个残碑（`ch4_vault/Stele1`、`ch4_hub/Stele1`）
   各自只发一次；重载同房不重复；隐藏书库首次发现有反馈并揭示地图，重载不
   重复播报。第 4 章计划每房最多 1 箱/1 碑，故「一房多内容」按跨房节点 id
   覆盖；底层多内容管线由第 2 章验收锁定。
6. **战斗**：`ch4_branch_a` 两场遭遇逐场锁门（两侧门碰撞层 1）/清怪/开门/
   按节点 id 发奖励，互不串扰；重载不重生已清波次；其余四个战斗遭遇
   （`branch_b/Arena`、`well/Arena`、`well/Arena2`、`elite/Arena`）在真实
   区域生成并逐区校验实际精灵 = 计划波次；清房计数按计划 7 个节点推进到 7
   （HUD 分母 8），事件节点计入一次，Boss 区不占普通波。战斗密度只记录：
   大图每遭遇 2 只 vs 旧世界每房 3–4 只。
7. **捷径/隐藏**：`hub_shortcut_entry` 屏障初始封闭，测试注入 `ch4_shortcut`
   后开门并写入 `stored`；真实重载后仍开；MDS 存档含能力、屏障对象与访问图；
   到达门 `shortcut_arrival` 无出向转移，`use()` 无效。全程没有新增任何游戏内

## 性能基线（headless，Godot 4.7.stable.official.5b4e0cb0f）

原始构建耗时（`fade_time = 0`，正常游戏由 0.22 秒淡入覆盖），两次运行区间：

- 普通区首次（进入顺序）：入口 **14.5–16.0 ms**、支路 A **16.4–18.4 ms**、
  支路 B **16.2–18.6 ms**、枢纽 **16.6–19.7 ms**、纵井 **16.3–18.3 ms**、
  书库 **12.1–14.5 ms**、事件 **12.6–14.9 ms**、精英 **14.9–17.3 ms**。
- Boss 区首次 **71.4–79.7 ms**（场景/立绘/着色器冷启动）；套件内热加载
  **45.6–45.9 ms**。
- 普通区热加载 **12.3–16.6 ms**（书库 12.3、枢纽 16.6）。
- Boss 区关闭动态背景 **11.6–12.0 ms**；关闭天气 **38.0–38.5 ms**；
  不生成 Boss **21.7–22.8 ms**。
- 真实门过渡（0.22 秒淡入，入口 `right1` → 支路 A）**236.1–243.8 ms** 墙钟。

说明：headless 无垂直同步/帧率上限，单帧耗时没有代表性；本作大区按
「门 + 淡入」过渡、世界 `seamless_rooms = false`，因此记录门过渡墙钟而不是
「无缝切换尖峰」。普通区构建远低于一帧预算；Boss 首次尖峰与动态背景开销由
0.22 秒淡入覆盖，未发现需要本程处理的性能缺陷。
