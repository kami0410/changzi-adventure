# 2026-11-11 · 1.1.0 全方位优化

用户诉求：安卓卡、画面不够好、AI 能调用的权限太少；之后追加「敌人和 Boss 没有连贯动作帧」「怪站在头上打不到」「画面可以用代码优化，面面俱到」。

## 做了什么

- **性能**（`9778bc0`）：`Perf` 画质档位、后台预热、特效上限、手机帧节奏。
- **头顶的怪**（`cf49711`）：敌人从玩家头上滑落。
- **动作帧**（`f86bcbc`）：16 敌人 + 4 Boss 的 Magpie 动作表 → `tools/import_magpie_sheets.py`。
- **AI 权限**（`4502354`）：`WorldActs`（45 动词、9 触发、11 倍率）、`ActLexicon` 离线读法、`SpeakBar`、AI NPC 记忆与祝福、HUD 规则列表、存档。
- **画面**：角色着色器亮度修正、身份描边、`DepthHaze`、`SurfaceEdge`、HUD 渐隐面板 / 血条拖尾 / 低血泛红、输入条墨底配色。
- 决策见 [ADR](../decisions/2026-11-11-world-acts-1.1.md)；规则见 GDD「1.1.0 规则」。

## 1.1.1 热修（同日）

- 用户反馈 Windows 进关直接卡死。复现：窗口模式下 `Warmup.finish()` 卡在 `load_threaded_get("res://scenes/main.tscn")`。1.1.0 发布前的测试没有覆盖「窗口模式 + 从 Hub 门进关」：集成套件是无头的（预热不启动），截图脚本直接加载主场景，模拟器只走到 Hub。
- 修复见 ADR 第 15、16 条；六个时间点（0.05–8 s）进关均正常，导出包内容用编辑器二进制 `--main-pack` 复跑正常。导出的 exe 本体没有办法脚本驱动，未直接验证。
- 用户反馈安卓安装提示没有签名：`apksigner verify` 显示包有 v2 / v3 签名，但证书是 Godot 调试证书、没有 v1 签名；部分国产系统会把调试签名当作未签名或不可信。需要用户决定是否建立正式签名。

## 没验证 / 留给下次

- **真机帧率没有测**：只有桌面与（若可用）模拟器；画质档位在真实手机上的效果需要用户反馈。
- AI 改写世界只用假响应和离线读法测过，没有连真实模型跑整局。
- 标题页、Hub、图鉴、背包、结局等纸面界面这次只确认了没有被着色器修正影响，没有重新设计。
- 中文语音仍是 SAPI 原型；Android 仍是调试签名。
