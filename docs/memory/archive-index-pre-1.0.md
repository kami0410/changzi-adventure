## 游戏概览

- **昌子大冒险**（slug：`changzi-adventure`）
- 2D 横版动作 Roguelite；核心是道具/构筑，语言同时作为构筑与叙事核心。
- 版本 **`1.0.0` 正式版**（用户 2026-11-08 确认；第 1–4 章 + 五结局；1.0 全套美术/言灵权能/异象/每日挑战/配乐 v2/五位 NPC）；之后修复走 1.0.x（[版本策略](decisions/2026-11-02-versioning.md)）。
- 目标：Chapter 1 demo（Windows 优先）；范围见 [Chapter 1 demo ADR](decisions/2026-11-03-chapter1-demo.md)。
- 昌子：失忆的宇宙史官，被克苏鲁式污染侵蚀，在破碎末日世界找回权柄与记忆。
- [GDD 与 0.11 规则](../GDD.md) · [剧情圣经](../story-bible.md) · [素材许可](../../ASSETS.md) · [角色像素概念](../../assets/concept/characters/README.md)。

## 世界与系统

- 语言：词 → 短语 → 权柄；污染 0–100；见 GDD §7。言灵 v3 组件→效果表见 [AI 言灵](../ai-skill-hook.md)。
- 战斗：2 武器 + 2 短语 + 1 权柄；墨量资源；见 GDD §8。武器可掉落/拾取（E），换装时旧武器掉在身后。
- 权柄：续命/改写为基底；吞噬（污染 ≥ 40，伤害最高 ×1.6）与归档（记录 ≥ 2，死亡带一件物品到下一局）按条件追加；见 [T17 记录](sessions/2026-11-04-t17-authorities-trust-gallery.md)。
- 难度：平静/墨雨/深渊/噩梦四档；生命/伤害、收益、污染倍率见 [平衡与权限 ADR](decisions/2026-11-02-balance-authority.md)。
- 成长：档案馆祭坛（生命/墨量/言灵伤害/污染抗性，成本逐级上涨；长期设计无上限，demo 每方向上限 10 级，`ArchiveData.MAX_LEVEL`）+ 词条熟练度（累积递减）。
- AI NPC：对话可执行白名单职能（讨价还价/锻造等），每 NPC 每次回 Hub 一次破例。
- 信任：4 档陌生/熟悉/信任/托付，阈值 0/2/6/12，由 `npc_trust` 现算（无新存档键）；影响对话态度、离线/AI 回复、商店/锻造折扣、托付免费锻造、起始残页。
- NPC 个人事件（第 65 程）：可见三 NPC 各一个一次性 Hub 事件（陆沉·红色文件夹/信任 6、阿砚·再烧一次炉/托付 12、咕噜·不卖的「永」/熟悉 2），另需 `Profile.demo_cleared`；只记 `[npc] events` 标志、零奖励、读完最后一行才记录；闻烬/白榆仍不可见无事件。见 [session](sessions/2026-11-06-npc-personal-events.md) · [ADR](decisions/2026-11-06-npc-personal-events.md)。
- 结局余味（第 66 程，叙事审计 E3）：`EndingEchoData` 给五结局 × 五 NPC 各一句余味（25 句）+ 每结局一段同时回收「笑面史官身份 / 最后一页」的回收段（5 段）；结束屏 `Echoes` 与已解锁画廊展示，未解锁不泄露；结局 id/标题/正文/判定/`Profile.endings` 记录与存档格式不变；写作时 demo 不可达的复原/焚毁余味照写并由测试层验证（第 91 程起第 1–4 章全线可达：复原经跨章仁慈 ≥ 2 且污染 < 60，焚毁走第 4 章章末「焚毁名册」）。见 [session](sessions/2026-11-06-ending-text-thickening.md)。
