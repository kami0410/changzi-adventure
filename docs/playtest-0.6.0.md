# 昌子大冒险 0.6.0 AI 言灵版

Windows：`build/windows/changzi-adventure.exe`；Android：`build/android/changzi-adventure.apk`（debug，未真机验证）。

## 这一版的核心

### AI 言灵（可选）

游戏默认仍然完全离线。AI 是“解读这句话”的升级，不是运行前提：

1. F10 → AI 言灵设置。
2. 选 Ollama（本地默认）、OpenAI 兼容接口或 Anthropic。
3. 填接口、模型、密钥，启用并保存，点“测试连接”。
4. 语言图鉴输入一句话，点“AI 解读”。
   - 先出现本地推演；
   - 状态显示“AI 正在读这句话…”；
   - 成功后显示 `[AI]` 结果；失败保留本地结果并说明原因。

**隐私**：只有点“AI 解读”才发送当前这一句；密钥只存本机 `user://ai_config.cfg`，不写进 PCK/APK；共享版本请用自建代理，不要把主密钥放进客户端。详见 [AI 言灵说明](ai-skill-hook.md)。

**当前开发环境没有 Ollama、也没有可用 API key**，所以本轮没有做真实联网调用；协议构造、响应解析、白名单/长度/数值钳制、配置读写、本地编译路径都有单元测试。AI 的真实质量与费用需要你用自己的服务验证。

### 同时保留的 0.5 内容

- 50 个可收集词 + 冰/风/光/影/梦/星/镜/歌等借用概念。
- 言灵 v2：识别 / 借用未收录 / 意图 / 形态 / 稳定度。
- 四章四 Boss：墨雨档案馆 → 呼吸废墟 → 无光海 → 笑面剧场。
- 残页经济与每章商店；梦魇难度；减弱震屏/闪屏。
- 六首循环配乐、22 段中文旁白（SAPI 原型）。

## 试玩重点

1. 不配置 AI，确认游戏完全离线可玩，AI 按钮只提示未配置。
2. 如果你有 Ollama：`ollama pull qwen2.5:7b`，设置里选 Ollama，测试连接，再输入“让雷落在火里”“把记忆烧成回声”。
3. 观察 AI 结果是否仍符合本地形态/数值上限；非法输出应回退离线。
4. 检查“AI 解读”是否只在点击时发送、是否不会自动装备。
5. 第四章、商店、梦魇与 50 词仍然成立。

## 仍然不是完整商业版

- 第四章专属插画/最后的读者立绘未生成（Magpie 额度限制）。
- 配音为 SAPI 原型；配乐为程序合成。
- 没有独立手绘逐帧图集；Android 未真机验证。
- AI 未做代理限流/审核/计费；共享版本需要自建代理与合规处理。
