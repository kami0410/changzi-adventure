# 术语表

- **Roguelite / Roguelike**：一局一局推进、死亡后重来；Roguelite 通常保留部分永久成长。
- **Run（一局）**：从开局到死亡或通关的一次完整流程。
- **Build（构筑）**：一局内武器、道具、被动的组合方式。
- **Item synergy（道具联动）**：两个或多个道具组合后产生额外效果。
- **Meta progression（元进度）**：跨局保留的解锁、资源或能力。
- **Vertical slice（垂直切片）**：范围很小但完整可玩的一段，用来验证核心体验。
- **Greybox（灰盒）**：用简单几何体和占位色验证玩法，不追求美术。
- **GDD**：游戏设计文档，本项目在 `games/<slug>/docs/GDD.md`。
- **ADR**：架构/设计决策记录，放在 `docs/memory/decisions/`。
- **Memory index**：常驻的小索引，按需加载主题记忆文件。
