# ADR-0001：采用 Godot 4.7.2 stable

## 状态

已接受（2026-10-31）。

## 背景

- 第一款游戏：2D 小体量，Windows 优先，后续 Android。
- 团队以美术/策划为主，编程较少。
- 偏好开源免费、可控。

## 决策

统一使用 **Godot 4.7.2 stable 标准版 + GDScript**，2D + GL Compatibility；
Windows 与 Android 都走原生导出。

## 理由

- MIT，无版税，源码可控。
- 2D 管线成熟，编辑器完整，GDScript 对非程序员友好。
- Windows 导出零配置；Android 官方支持成熟，M0 已实际导出签名 APK。
- 中文文档完善，AI/MCP 生态活跃（godot-ai、gamedev skills）。

## 后果

- 每款游戏独立 Godot 项目、独立 git 仓库。
- 引擎固定在 `tools/godot/`，升级必须同步 `tools/manifest.json`、模板和所有游戏。
- Android 导出依赖本机 JDK/Android SDK；换机器要重新配置。
- 若未来以国内移动渠道为主，再评估 Cocos Creator。

## 备选

GDevelop（零代码）、Cocos Creator（TS/移动）、Phaser + Electron/Capacitor（Web 复用）。
