# 第一款游戏：GDD 未定问题

## 已确定

- 名称：**昌子大冒险**，slug `changzi-adventure`。
- 类型：2D 横版动作 Roguelite。
- 参考：《死亡细胞》的战斗节奏、《以撒的结合》的构筑随机性。
- 主角：昌子，失忆的宇宙史官，被克苏鲁式污染侵蚀，在破碎末日世界找回权柄与记忆。
- 核心支柱：**道具/构筑足够丰富**；语言同时作为构筑核心与叙事核心。
- 角色：主角、5 名照片 NPC、笑面史官最终 Boss，另有 5 名原创 NPC（见角色参考）。
- 次要目标：画面精美；类似《艾尔登法环》的碎片叙事与多结局，先做到及格。
- 首款游戏先做小体量，不按满配做。

## 待定

1. **美术风格**：已定高精度像素（2026-10-31）；分辨率、配色、镜头比例待细化。
2. **语言系统**：词/短语/权柄的层级；哪些词能组合；解码如何随记忆推进？
3. **战斗模型**：近战/远程比例、武器槽位、翻滚/格挡/冲刺、同时携带几把武器。
4. **道具系统**：武器、主动、被动、词条、稀有度、套装/进化、污染/诅咒。
5. **单局结构**：房间制、横版关卡、分支地图？一局多长？死亡后保留什么？
6. **关卡生成**：程序生成、手工房间、两者混合？首批几个生态区？
7. **叙事**：碎片放在哪里？多结局如何触发？笑面史官与昌子的关系。
8. **垂直切片范围**：首个可玩版本包含多少武器/道具/敌人/Boss。
