# 昌子大冒险

2D 横版动作 Roguelite。昌子是失忆的宇宙史官，被克苏鲁式污染侵蚀，在破碎的末日世界里战斗，找回权柄与记忆。语言同时是构筑核心与叙事核心：读懂多少词，就拥有多少力量，也离真相与疯狂更近一步。

- 引擎：Godot 4.7.2 标准版 · GDScript · 2D / GL Compatibility
- 仓库：https://github.com/kami0410/changzi-adventure
- 设计文档：[GDD](docs/GDD.md) · [剧情圣经](docs/story-bible.md) · [记忆索引](docs/memory/MEMORY.md)

## 当前可玩范围

当前 demo 可玩第 1–4 章：从标题页进入 Hub，完成教学后出发，依次打通第一章「墨雨档案馆」、第二章「呼吸废墟」、第三章「无光海」与第四章「笑面剧场」。每章章末各有一次选择；第一、二、三章结束后直接接续下一章的开场，第四章章末选择后战役结束、进入结局屏，按 R 回到 Hub 继续挑战。

- **第一章「墨雨档案馆」**：9 个房间区域——4 个战斗房、1 个精英房、1 个事件房、1 个休整房、1 个隐藏书库、1 个 Boss 房；清房目标 6，之后是 Boss「墨骸史官」的三阶段战（书页潮 / 页风暴 / 封页与镜写）。
- **第二章「呼吸废墟」**：9 个连通大区、22 扇门、纵向井与电梯、单向落台、长椅检查点、捷径、事件区与隐藏书库；清房目标 7，Boss「肺钟守卫」有呼吸、钟摆与钉子三个阶段。
- **第三章「无光海」**：同一套大区管线；清房目标 7，Boss「最后的读者」有镜面弹幕、读页封印与空白页承伤窗口。
- **第四章「笑面剧场」**：9 个连通大区、22 扇门、纵向井与电梯、单向落台、长椅检查点、捷径、事件区与隐藏书库；全章背景使用专属剧场插画；清房目标 7，Boss「笑面史官」有纸页波、镜面弹幕、墨雨与改写；章末选择后战役结束、进入结局屏。
- **武器与遗物**：行为各不相同，可掉落、拾取与切换。第一章的奖励与残碑用 6 把武器、6 件遗物；第二至四章从完整内容库抽取。内容库共 12 把武器、9 件遗物、14 种敌人。
- **95 个词条**（39 名词 / 29 动词 / 27 修饰）：首次开局拥有 18 个——6 个可直接读，12 个以未解码残页词持有；解码、词条熟练度与已发现的短语跨局保存。
- **言出法随**：1–4 个词任意组合，离线推演完整可用；未解码的词也能施放，但更不稳定。AI 解读是可选设置。
- **局内循环**：清房三选一、残页商店、宝箱、残碑、休整、隐藏书库、四档难度、局内存档与续玩。
- **Hub 与成长**：与陆沉、阿砚、咕噜对话；档案馆祭坛可升级生命 / 墨量 / 言灵伤害 / 污染抗性（demo 每方向上限 10 级）；记忆碎片、信任与结局跨局保留。闻烬、白榆暂不在 demo 中出场。
- **0.14 新增**：
  - **翻滚**：带无敌帧、可向后滚、身形压低能钻过弹幕；空中改为一次冲刺；无敌帧内被击中触发「完美闪避」（回墨、冷却清零、顿帧）；翻滚末尾出手必是重击。
  - **召唤电梯**：第 2–4 章电梯平时停靠，在两端呼叫面板按 E 召唤、站上去按 E 升降，速度约为原来的 4 倍。
  - **地图随机性**：第 1 章战斗房每局抽取不同平台布局；四章所有普通战斗加入「遭遇变数」——敌人替换、加人、精英 / 迅潮 / 群潮词缀与随机站位，同一局读档不变。
  - **美术**：四章各自的像素地块、背景压暗分层、纵井背景不再镜像穿帮、底部 HUD 不再挡住地面。
- **章末选择与结局**：五个结局全部可达成，判定只看战役结束（第四章末）时的状态——「焚毁档案」= 第四章末选「焚毁名册」；「深渊回响」= 未焚毁且污染 ≥ 60；「复原」= 未焚毁、污染 < 60 且本局仁慈 ≥ 2（四次章末选择中至少两次选带「仁慈 +1」的选项，第四章对应「重写名册」）；「未完的注脚」= 其余通关结果；「记录中断」= 失败结局。已解锁结局可在标题页「结局画廊」查看。
- **捷径**：第 2–4 章到达枢纽区即打通一扇回到入口的单向暗门，解锁随存档保留。

## 核心系统

### 言出法随

- 在语言图鉴里输入 1–4 个词（顺序不限），推演器会给出形态、墨耗、稳定度与共鸣；也可以直接点选已拥有的词。
- 13 种法术形态由词义与组件决定：焰、噬血、裂空、迟滞漩涡、护写、回声、渊蚀、墨刃、追踪弹幕、贯光、地裂、坠星、领域。
- 未解码的词可以施放，但稳定度更低；解读词条本身也是推进剧情与构建的一部分。
- 离线推演完整可用。设置里可选 Ollama、OpenAI 兼容接口或 Anthropic；只有点「AI 解读」才会发送当前句子，密钥保存在本机。AI 返回仍要经过本地形态 / 词义白名单校验。

### 权柄

Boss 战后从权柄池中选择一个，带进本局余下的流程：

- **续命**：死亡时复活一次，保留当前构筑。
- **改写**：重掷一次奖励，或改写一个房间的规则。
- **吞噬**（污染 ≥ 40 时追加）：把污染转化为伤害，污染越高越强，100 污染时约 +60%。
- **归档**（本局记录 ≥ 2 时追加）：死亡后保留一件物品到下一局。

### 信任分层

- 四档：陌生（0）/ 熟悉（2）/ 信任（6）/ 托付（12）。信任值不封顶，档位由当前数值现算。
- 档位影响对话态度、商店与锻造折扣、下一局的起始残页；对阿砚达到「托付」后，每次回 Hub 有一次免费锻造。
- 陆沉、阿砚、咕噜各有一个一次性 Hub 个人事件，需要先打通第一章并达到对应档位；读完最后一行才记录，中途关闭不消耗，事件本身不给奖励。

### 结局画廊

- 五个结局：复原、焚毁档案、深渊回响、未完的注脚、记录中断。
- 标题页可进入结局画廊；只有已解锁的结局会展示正文，未解锁保持占位。
- 已解锁结局会额外展示五名 NPC 的余味与一段回收「笑面史官 / 最后一页」的文本。

## 运行

1. 用 Godot 4.7.2 标准版打开 `project.godot`，按 F5 从标题页开始。
2. 在 Hub 与陆沉对话完成教学，走到右侧传送门按 E 出发。
3. 每章章末都有一次选择：第一章后接续第二章，第二章后接续第三章，第三章后接续第四章，第四章章末选择后战役结束、进入结局屏，按 R 回到 Hub。
4. 记忆碎片、解码词、信任、档案馆升级与已解锁结局会保留到下一局。
5. 配乐为 6 首原创循环曲目，可在设置里调主音量；仓库不含引擎与构建产物，发行包与平台支持以 Release 说明为准。
