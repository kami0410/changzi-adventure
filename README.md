# 昌子大冒险

2D 横版动作 Roguelite。昌子是失忆的宇宙史官，被克苏鲁式污染侵蚀，在破碎末日世界中战斗，找回权柄与记忆。语言同时作为构筑核心与叙事核心。

## 言出法随怎么用

1. 按 C 打开语言图鉴。
2. 在“言出法随”输入一句话（例如“让雷落在火里”“把记忆烧成回声”）。
3. 点“推演”，看形态、墨耗、稳定度与共鸣。
4. 点“装备到 [Q]”或“装备到 [F]”，关闭图鉴后按对应键施放。

也可以不用输入框，直接点选 1–4 个已拥有的词；两种方式共用同一套离线推演，AI 数值不再设上限，无法理解的句子进入“深渊污染”。

### 可选 AI 解读

1. F10 打开设置 → **AI 言灵设置**。
2. 选服务：Ollama（本地，默认）、OpenAI 兼容接口、或 Anthropic；填接口地址、模型、密钥。
3. 启用并保存，点“测试连接”。
4. 在语言图鉴输入一句话，点 **AI 解读**；本地结果先出现，AI 返回后再升级，失败则保留本地结果。

只有点“AI 解读”时才发送当前句子；密钥保存在本机 `user://ai_config.cfg`，不写进游戏包。共享版本请用自建代理，不要把主密钥放进客户端。详见 [AI 言灵说明](docs/ai-skill-hook.md)。

## 运行

1. 用 Godot 4.7.2 打开本目录的 `project.godot`。
2. 按 F5 从标题界面开始；进入「最后的档案馆」后与陆沉对话，得知名册被撕走三页。
3. 走到右侧传送门按 E 出发，依次穿过四章；章末选择会改变结局。
4. 单局死亡/通关后按 R 回 Hub，记忆碎片、结局与残碑记录会保留。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 跳跃 | 空格 |
| 攻击 | J |
| 翻滚 | L |
| 短语 1 / 2 | Q / F |
| 对 NPC 言灵 | Y |
| 操作说明 | H |
| 设置 / 键位 | F10 |
| 切换武器 | 1 / 2 |
| 背包 | Tab |
| 语言图鉴 / 造句台 | C（选 2–3 个词 → 预览法术形态 → 装备到短语槽） |
| 读取残碑 / 商店 | E（站在可选平台的残碑或纸人交易所旁） |
| 设置（全屏/音量） | F10 |
| 暂停 | P / Esc |
| 结算后回 Hub | R / 返回按钮 |
| 重开单局 | 暂停菜单中的重新开始 |
| 触屏 | Android 自动显示虚拟按钮 |

音频：五首程序化循环配乐 + 18 段中文旁白 + 生成式 SFX；可在设置里调主音量。配音为 SAPI 原型，正式发行需替换。
